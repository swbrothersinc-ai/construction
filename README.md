# SW Brothers Construction — Phase 1 Homepage Prototype

Standalone static website for `construction.swbrothersinc.com`, separate from the existing US technology website.

## Preview
Open `index.html` in a browser or serve locally using `python -m http.server 8000` from this directory.

## Cloudflare deployment
1. Create a separate GitHub repository and commit this entire directory.
2. Deploy as a new Cloudflare Workers Static Assets project or Pages project, with site root as output directory (no build command required).
3. Add `construction.swbrothersinc.com` as the custom domain in Cloudflare and confirm HTTPS.
4. Replace email-based inquiry with a server-side form endpoint, spam protections and an appropriate privacy notice before collecting/storing submissions online.
5. Verify final legal entity details, any qualifications and business registrations before publishing them.

## Important notes
- This is a website prototype, not a deployed live site.
- The brand uses the supplied SW monogram.
- No invented tender awards, PEC status, registration numbers, projects or customer testimonials.
- The contact form opens an email draft; it does not send data to a server.
